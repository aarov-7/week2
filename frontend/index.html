Rahti compared to docker + pouta deployment

Docker Compose assumes you are running a specific set of containers together on a single machine. That means you are in charge of starting them and figuring out how to handle data and configuration files yourself.

Rahti operates on a desired state model. The user tells the cluster how their app should look, and it works continuously in the background to keep it that way. If a container crashes Rahti automatically recreates the users pods on its own.
