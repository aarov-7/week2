What would a mid-size company store to the Amazon Glacier? What not? Why? What other large cloud backup or mass storage providers are there?

A mid-size company could use Amazon Glacier to store files that need long term storage. These could include legal paperwork, system backups and data archives. They would not store files that need to be updated or checked on regularly. These could include active assets for websites or live user databases. The company wouldn't use Amazon Glacier for files that don't require long term storage, because moving files from Glacier takes a long time and adds on to the otherwise low costs. Other popular mass storage providers include Google Cloud Storage and Microsoft Azure Blob Storage.

Compare some large web hosting / web hotel provider offerings (not CDN)

Hostinger has the lowest intro and renewal pricing with 13 data centers globally. It's the most budget friendly option. Bluehost is best for first time wordpress creators and contains highly detailed guides on wordpress setup and onboarding. SiteGround is the costliest but the fastest and most secure option targeted towards e-commerce and agencies.

Compare few cloud data storage provider features and pricing (either for home users or for enterprises)

Microsoft OneDrive has pricing options from a free 5gb to an up to six person family plan with each person having one terabyte for a hundred dollars a year. OneDrive includes native windows and Microsoft Office integration. Google One includes 15gb of data with it's free plan and up to 2tb of data with it's premium tier. It's easy to use on android and contains seamless integration with google applications such as gmail, docs and photos. Apple iCloud comes with a free 5gb of data up to a 12tb option. It's best for iphone, ipad and mac users and includes deep integration with iOS and macOS.

Describe reasons why so many (most?) companies are using cloud based email and calendar services

Modern organizations favor cloud-based email and calendar platforms because they eliminate the costly and laborious burden of maintaining their own server infrastructure. By adopting subscription-based solutions like Microsofts 365 or Googles Workspace, businesses convert large capital investments in physical hardware into predictable operating expenses while gaining continuous access to high-availability global data centers. These cloud environments provide superior built-in cybersecurity, using automated threat intelligence and multi-factor authentication to block sophisticated phishing attacks and malware far more effectively than isolated internal systems can. Furthermore, cloud platforms naturally support flexible hybrid work environments by instantly synchronizing schedules, contacts, and messages across mobile devices and remote locations without complex network setups. Deep integration with real-time video conferencing, cloud storage, and shared document tools transforms basic email and calendar functionality into a centralized collaboration hub that scales effortlessly as an organization grows.
